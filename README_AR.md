# منصة إنشاءات للاستشارات الهندسية — تسجيل مجاني مبسط

## آلية الدخول الحالية
- تسجيل مستخدم جديد بالاسم الكامل ورقم الهاتف فقط.
- عودة المستخدم تكون بإدخال الاسم ورقم الهاتف المسجلين.
- لا توجد كلمة مرور أو Google OAuth أو OTP أو بريد إلكتروني.
- لا توجد اشتراكات أو رسوم أو حدود لعدد مرات استخدام أدوات التدقيق.
- يبقى `etabs_tables.py` ملف التشغيل الرئيسي، وتبقى أدوات ETABS والحسابات والرسوم والتقارير ضمنه.

## التشغيل المحلي
```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
pip install -r requirements.txt
streamlit run etabs_tables.py
```

## قاعدة بيانات المستخدمين
ينشئ التطبيق تلقائياً ملف `platform_users.db` بجانب `etabs_tables.py` ويحفظ الاسم ورقم الهاتف. لا تحذف الملف إذا أردت الاحتفاظ بالمستخدمين المسجلين محلياً.

## تنبيه أمني وتشغيلي مهم
هذا تسجيل مبسط وليس تحققاً من الهوية؛ أي شخص يعرف الاسم ورقم الهاتف يستطيع محاولة الدخول بهما، ولا توجد حماية من انتحال الحساب. كما أن SQLite المحلية على Streamlit Community Cloud قد لا تكون دائمة عند إعادة تشغيل البيئة أو إعادة نشرها. قبل الاعتماد التجاري أو حفظ بيانات حساسة، ينبغي إضافة تحقق مناسب ونقل قاعدة البيانات إلى PostgreSQL مُدار.
